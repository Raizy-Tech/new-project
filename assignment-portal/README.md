# AssignFlow — Assignment Submission Portal

Hackathon MVP for the Assignment Submission Portal problem statement.

## Included
- Student and Professor authentication/registration
- Professor assignment creation with deadline and PDF metadata
- Student PDF submission with automatic late detection
- Professor submitted/late/missing view
- Marks and remarks
- Student grade/feedback visibility
- Responsive UI
- Browser localStorage persistence for a zero-backend demo

## Demo accounts
- Professor: professor@demo.com / prof123
- Student: student@demo.com / student123

## Important
This version is intentionally deployable as a static MVP. Data and uploaded PDFs are stored in the browser's localStorage, so it is suitable for a hackathon demonstration but is not a production multi-user backend.
