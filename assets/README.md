# SM Tailoring image assets

The homepage is ready for real photography.

Recommended files:
- hero.jpg — wide, high-resolution photo for the homepage background.
- blouse-01.jpg, blouse-02.jpg, blouse-03.jpg — optional future lookbook images.
- atelier.jpg — optional photo of Sivamma's tailoring workspace.

For the strongest result, use original photographs of the real garments, workspace and craftsmanship. Keep the hero image wide and avoid placing important text near the center of the image because the site overlays the headline on top of it.

No image is required for the site to work: the CSS has a warm editorial fallback.
